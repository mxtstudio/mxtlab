# Security Policy

## Supported Versions

Security fixes are applied to the current production version of MXT Lab. Older deployments and unsupported branches may not receive security updates.

## Reporting a Vulnerability

Please do not publish suspected vulnerabilities, student data, access tokens, screenshots containing personal information, or exploit details in public issues.

Use GitHub's **Report a vulnerability** feature in the repository Security tab to submit a private vulnerability report when it is available. Include:
- A concise description and affected component.
- Reproduction steps using test accounts and synthetic data.
- The potential impact and any practical mitigation.

If private vulnerability reporting is unavailable, contact the repository maintainer through the maintainer's GitHub profile and request a private channel before sharing technical details.

## Response

Reports will be acknowledged as soon as practical, investigated, and prioritized according to severity and impact. Please allow time for a fix and coordinated disclosure before publishing details.

## Student Privacy

Do not include real student names, contact details, school identifiers, grades, learning records, or uploaded documents in vulnerability reports. Use synthetic test data.
