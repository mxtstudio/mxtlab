# MXT Lab — Interactive Agriculture Study Platform

MXT Lab is a free interactive Agriculture study platform designed for Grade 9-12 students in Papua New Guinea. It covers all five strands of the Agriculture curriculum: Crops, Animals, Aquaculture, Natural Resources, and Agribusiness.

## Features

- **Interactive Lessons**: Comprehensive lesson content with key terms and summaries.
- **Quizzes**: Engaging quizzes to test and reinforce knowledge.
- **Downloads**: Access to educational resources and study materials.
- **Teacher OS**: A dedicated platform for teachers to plan and manage lessons.

## Project Structure

- `index.html`: The main landing page.
- `lessons/`: Contains individual lesson HTML files.
- `assets/`:
  - `css/`: Stylesheets for the website.
  - `js/`: JavaScript files for interactivity and content.
- `Image/`: Image assets used across the platform.

## Deployment

The project is configured for deployment on Vercel.
